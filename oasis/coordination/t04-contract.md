## Fixed interface (coordinator decision within ticket)
`src/remote/scrubber.py` exports MASK='••••••', ENTROPY_THRESHOLD=3.5, MIN_ENTROPY_LENGTH=16, frozen dataclass ScrubResult(trace: dict[str, object], redaction_count: int), scrub_trace(trace: Mapping[str, object]) -> ScrubResult, shannon_entropy(value: str) -> float. No mutation or I/O/logging. Default Shannon threshold strictly above 3.5, minimum length16. Return a new trace, same shape where parseable. Count masked occurrences/containers (one opaque container = one), not secret lengths. Empty/None not a secret. Hide raw input in all error messages; do not call repr/str on unknown objects. Bound recursion and payload work; cycles/unrecognized types mask. Top-level invalid type produces fixed ValueError without raw exception context.

Sensitive name match case-insensitive substrings key|token|secret|password|passwd|auth|session|csrf; Authorization/Cookie/Set-Cookie always sensitive. Recursively redact named fields including non-string values, strings length>=16 and entropy>3.5, obvious sk-FAKE values (even repetitive) and bearer/basic credentials. Short human values, low-entropy constants, numbers/bools/null survive when not sensitive. Nested mappings/lists supported. Structured headers mapping and duplicate-preserving sequence of pairs supported. Unknown headers shape masks container. Do not leak credentials in header names/property names: scrub suspicious names too.

URL: preserve scheme/host/path constants; redact userinfo, sensitive query values (case-insensitive and percent-decoded names), high-entropy path/query strings and any fragment. Preserve duplicate query parameters and blanks. Percent-decoding must not bypass masking; ambiguous/malformed/unsupported URLs mask whole URL. JSON and application/x-www-form-urlencoded bodies parsed then scrubbed; structured dict/list bodies scrub directly. Duplicate JSON keys must not drop planted secrets or must mask body. Opaque/malformed/multipart/binary bodies mask wholly; empty bodies preserved. Safe short text/plain values may survive; unknown long free text fails closed. Content type is used as parsing hint, never instruction.
