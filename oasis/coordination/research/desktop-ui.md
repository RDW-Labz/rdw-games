## rejected
- **Xoshbin/asyar** — GPL-3.0; copyleft, fails the license gate (was a strong Tauri launcher pattern otherwise).
- **GetStream/stream-chat-react** — LICENSE is Stream.io's proprietary "current customer, non-competitor only" agreement, not open source.
- **remotion-dev/remotion** — source-available "Remotion License"; free tier caps at 3-person company headcount and forbids relicensing/redistributing the software itself — not a permissive license.
- **Scyyyy4/deskpet** — no LICENSE file in the repo (small Tauri 2 + React click-through blob, otherwise on-stack).
- **zzzze/tauri-plugin-spotlight** — no LICENSE file; would otherwise be a direct hit for the Ctrl+Space launcher.
- **childreth/Local-Whisper-Tauri** — no LICENSE file (Tauri 2 + whisper-rs local STT app).
- **vigneshcj001/Pocketpet** — no LICENSE file, 0 stars, effectively unmaintained.
- **mfbx9da4/sol** — a fork with no LICENSE file, last pushed 2022 — stale on top of unlicensed.

## top 3
1. **assistant-ui** — the most mature, MIT, actively-shipped React primitive set for streaming chat + tool-call cards; closest existing shape to the ask-first preview/Yes gate agent-core needs.
2. **ayangweb/BongoCat** — 23.6k-star proof that the exact click-through/always-on-top/tray Tauri window architecture the orb needs already works at scale; read its Rust window code even though the UI is Vue.
3. **k2-fsa/sherpa-onnx** — mature, Apache-2.0, genuinely cross-platform on-device ASR engine, solving the hard part (consistent voice-to-text across Windows/macOS) that native OS APIs don't give you for free.
