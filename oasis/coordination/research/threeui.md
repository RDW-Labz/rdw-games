## DarkSoulsHoloCard technique

No page by this name exists publicly on ThreeUI (checked `/browse`, all category pages, site search, GitHub `routes.js`, and a direct URL guess that 404'd). What follows describes the technique of the two closest public cousins, Holographic Glitter Card and Halcyon Card, in plain words — not an invented page.

Both are built as a single card-shaped mesh with a custom fragment shader material, not layered CSS. The "foil" look comes from a shader that mixes a base surface color with a shifting rainbow/iridescent tint whose hue depends on the viewing angle (surface normal vs. camera direction) plus a moving noise field, so the color band sweeps across the card as you move the pointer — the same idea as real holographic foil, faked optically rather than photographed. Halcyon Card layers an engine-turned/guilloche pattern baked onto a canvas texture for the gold-border engraving, rather than drawing it live each frame — cheaper than a procedural pattern. Tilt-on-hover reads normalized pointer x/y across the card's bounding box and maps it to small rotation values on two axes, recentering when the pointer leaves. The "pointer light" is a virtual light or highlight term in the shader whose position tracks the same pointer coordinates, so specular hot-spots slide across the foil as if a light were following the cursor. Click-to-flip (Halcyon's "tap-to-open") is a rotation tween around the vertical axis from 0 to 180 degrees, typically swapping which face's texture is visible partway through the turn. Drag-rotate is the same rotation math driven by pointer-down movement deltas instead of hover position. None of this needs more than one mesh and one shader per visible card, which is consistent with the brief's plan of one shared renderer and static PNGs when off-screen or non-hovered.
