Notes on sources:
- WebDev Arena (arena.ai/leaderboard/code/webdev) scores multi-step, tool-using front-end generation head-to-head by human vote — closest public proxy to real Tauri/React UI work. Snapshot used: 2026-09-25, "795,514 total votes / 134 models."
- Design Arena (designarena.ai, mirrored by modelgrep.com and benchmarklist.com) scores single-shot design/3D output by blind human preference, with a dedicated "3D Design" category described as "generating three-dimensional scenes and geometry as code (Three.js, WebGL, shaders)." Different scrapes (2026-09-02 vs "Sept 2026" aggregator pages) show slightly different Elo numbers for the same models because the board updates live every ~2 hours — both are cited with their scrape dates rather than reconciled.
- No public data was found for: exact OpenRouter pricing fields for Claude Opus 5.5, Claude Fable 5.1, Claude Opus 5, GPT-6 Astra, or Claude Sonnet 5 (the public `/api/v1/models` listing did not have pricing populated for these entries at fetch time); a scored Design Arena "3D Design" entry for Claude Opus 5.5; a WebDev Arena entry for Kimi K3.

## recommendation

- **UI design jobs (React/CSS, Tauri desktop UI): Claude Opus 5.5.** It is #1 on WebDev Arena's agentic front-end leaderboard (Elo 1827, 2026-09-25) — the closest public proxy to real component/CSS-token work — and won a direct hands-on comparison against GPT-6 Astra on landing-page visual/creative quality.
- **Three.js/shader jobs (T50 holo cards): GPT-6 Astra.** It is #1 on Design Arena's dedicated 3D-as-code category (Elo 1464, Sept 2026), the only public leaderboard built specifically for Three.js/WebGL/shader generation. Caveat: OASIS's own astra/Codex-CLI worker has been out of credits since 2026-09-26, so until that's resolved, **Claude Opus 5.5** is the practical fallback for T50 (it has independent, dated hands-on evidence of strong Three.js/shader output, just no scored 3D-arena entry yet).
