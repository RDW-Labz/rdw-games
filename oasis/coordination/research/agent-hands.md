## rejected

- **Skyvern-AI/skyvern** — AGPL-3.0 (core repo), copyleft, fails the license gate.
- **dagucloud/dagu** (dagu-org/dagu) — GPL-3.0, fails the license gate; otherwise a nice small YAML DAG/workflow engine.
- **ansible/ansible** — GPL-3.0, fails the license gate; playbook YAML pattern isn't usable as a dependency.
- **open-webui/open-webui** — Custom "Open WebUI License": derived from BSD-3 but adds a mandatory branding/anti-endorsement clause and a required CLA on contribution — not a clean permissive license, fails the gate.
- **Miksus/rocketry** — MIT, but last commit 2023-11-15; inactive well past 12 months, appears unmaintained.
- **orieg/yaml-workflow** — MIT, but 3 stars and no visible adoption; too small/unproven to trust for a "real users" signal.
- **BryantVanOrden/OpenAgentFleet** — MIT, but 0 stars and the whole repo is a day old; unproven, no track record.

## top 3

1. **browser-use/browser-use + microsoft/playwright-mcp** — take the browser driver and the structured-tool schema for the "agent's own browser" ticket; wrap every page read as untrusted per the existing injection rule, don't trust either project's own defaults.
2. **coleifer/huey + agronholm/apscheduler** — pair them for local parallel task execution plus recurring/scheduled tasks on one desktop, with zero extra server infrastructure (both work off SQLite/files).
3. **agent0ai/agent-zero** — mine its memory design, Docker-isolated execution, and job scheduler for the T25 memory ticket and the parallel-tasks ticket; explicitly do not adopt its more permissive default-trust automation posture.
