## rejected
- **humanlayer/humanlayer** (Apache-2.0) — license is fine but the repo's own README says "the code here is pretty much all deprecated," pointing users to a closed hosted product (CodeLayer); the `@require_approval` SDK was removed. Don't take a dependency; the interrupt/approve idea is better read from `pydantic-ai`'s deferred-tool pattern above.
- **protectai/llm-guard** (MIT) — archived 2026-07-08, read-only, no active development.
- **protectai/rebuff** (Apache-2.0) — archived, last pushed 2024-08 (over 2 years stale); the vendored vector-DB + canary-token approach is also fairly heavy for OASIS's thin ask-first gate.
- **deadbits/vigil-llm** (Apache-2.0) — last pushed 2024-01, no activity since; fails the 12-month activity bar.
- **letta-ai/letta** (Apache-2.0, active, 24.9k★) — not a license or activity problem, but it's a full stateful "agent OS" that manages its own runtime and message history; heavier than T25 ("Remember this") calls for. `mem0`'s plain add/search API is the thinner fit — "do not build ahead."
- **openai/openai-agents-python** (MIT, active, 29.7k★) — solid HITL interruption/RunState design, but adopting it means running a second agent orchestration framework alongside agent-core's own loop. `pydantic-ai`'s narrower deferred-tool pattern above gives the same idea without the runtime.
- **OWASP/www-project-ai-testing-guide** — CC BY-SA 4.0. Fails the license gate outright (not on the permitted list), and it's a testing-methodology document, not code, so it wouldn't be "reused" so much as read.

## top 3
1. **microsoft/agent-governance-toolkit** — closest existing analog to OASIS's own ask-first gate + T28a injection defense in one MIT repo; borrow its policy schema and evaluator design rather than reinventing both from scratch.
2. **pyeventsourcing/eventsourcing** — a mature, dependency-light, BSD-3 immutable event store is most of what the append-only action log needs, without hand-rolling hash-chain logic.
3. **liu00222/Open-Prompt-Injection** + **NVIDIA/garak** — take their attack corpora as seed fixtures for T28a's pytest suite instead of writing "tool result carries an instruction" test cases from zero.
