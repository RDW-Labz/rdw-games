# Putt Drop

One-thumb neon mini golf for phones. Drag to aim, release to putt.
Phaser 4 + Capacitor (Android first). All art and sound are generated in code.

Free: holes 1-12. One in-app purchase ("Unlock full game") opens the rest.
No ads, no analytics, no accounts, no data collected.

Ships through RDW-Labz/ship-pipeline (`ship.config.yml`).
