# Putt Drop UI style

Pocket Park is the approved direction. The old neon guide is superseded.

- [Design system and tokens](design/system.md) — colors, typography, components, course art and performance.
- [Motion specification](design/motion.md) — every effect, park transitions, reward timing and reduced motion.
- [Screens and states](design/screens.md) — layouts, safe areas, purchase flows, errors and developer gallery.

Implement presentation values through `src/ui/tokens.ts` as defined in the design system. These specifications are builder contracts, not claims that the current game already implements them.

## Review checklist

- [ ] Review uses the three Pocket Park specifications above; no old neon values remain authoritative.
