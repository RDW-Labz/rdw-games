# Codenames

Names from Ready Player One. Product name is **OASIS**. Repo names are the plain names; codenames are what we call them in conversation and in the UI.

| Codename | Repo | What it is | Phase |
|---|---|---|---|
| **OASIS** | (the whole product) | The one world every employee plugs into | — |
| **Rig** | `desktop-app` | The app on your desk: installer, orb, side panel, full app, browser extension | 0 thin, 4 full |
| **Anorak** | `agent-core` | The guide inside every agent: loop runner, memory, model switch, secrets interface, Scoreboard skill | 0 |
| **Zemeckis** | `remote` | The watcher that records what you did and replays it as a button (proxy, scrubber, macros) | 0 |
| **Almanac** | `skills` | Shared and personal skills, tests, formats | 0 |
| **Gates** | `connectors` | One-click connectors and the catalog | 0–1 |
| **Keys** | (inside `agent-core` then `rag-pipeline`) | The secrets vault behind the `secrets` interface | 1 keychain, 3 vault |
| **Journals** | `rag-pipeline` | The company's searchable memory: drawers, ingest, retrieval, role gate | 3 |
| **Curator** | (inside `rag-pipeline`) | Retrieval: the librarian who finds it | 3 |
| **Scoreboard** | (inside `agent-core`) | Automated measurement that tunes the system | 0 |
| **Art3mis** | `agent-amber` | Amber's agent | 1 |
| **Parzival** | `agent-michael` | Michael's agent | 2 |
| **Garage** | `playbooks` | Playbooks, this plan, decisions, agent-template | 0 |
| **the Stacks** | (future, inside `desktop-app`) | 3D network view of agents, skills, connectors, drawers | 4+ |
| **Gunters** | `project-swarm` (Braden's existing repo) | The build crew. Not part of the product. | — |
