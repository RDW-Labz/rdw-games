# RDW Games

Sole active game-line repo for RDW-Labz. Folded from 12 game/market repos on 2026-11-08;
consolidated again on 2026-11-16 against the game-repos decision matrix. Feeds
game.cluerholdings.com.

## Layout

    cloned-free-games/       the pipeline's tracked artifacts (catalog, queue, scripts, docs)
    offline/                 awesome-offline-mobile-games — the offline collection (full copy)
    evidence/
      aaa/                   freegames/reports: scores.jsonl + per-game build/runtime verdicts + bin/
      cloned-free-games/     build logs + run screenshots promoted from cloned-free-games-temp
    shelf/                   (later) git SUBMODULE -> jmacluer-design/internal-hybrid-builds @ kaos-launch
    index.html               rendered catalog page (generated by the daily publish)
    RUBRIC.md                the judging rubric

## Deliberately NOT here

- **Shatterworld engine content.** This repo is public; Shatterworld is not cleared
  (9 CLEAR / 5 ATTRIBUTE / 9 REPLACE / 7 REMOVE). The engine's untracked 479 MB is preserved
  in the private repo `jmacluer-design/internal-hybrid-builds`, branch `shatterworld-branch`
  (commit `a71aa173`, see its `PRESERVATION-MANIFEST.md`). Only the already-tracked,
  already-public `shatterworld/` module tree lives here.
- **The 35 GB of clone sources** (`~/cloned-free-games/games/`) and the 16 GB AAA shield
  (`/mnt/models/cloned-free-games`). Regenerable; six live crons resolve those paths.
- **The 22 GB AAA build-farm scratch** (`~/freegames/work/`). Regenerable; only its
  `reports/` are kept, under `evidence/aaa/`.
- **game-backends.** Its own repo: `RDW-Labz/game-backends` (+ Gitea `michael/game-backends`).
  It is a library, not a game, and it has its own 15-minute writer.
